# APDS-9999_kernel_driver

This is a Linux Kernel Driver for the Broadcom APDS-9999 Digital Proximity and RGB Sensor

This sensor is interfaced via I2C and falls in the category that should be controlled via the Industrial I/O subsystem. Kernel Docs [here](https://www.kernel.org/doc/html/latest/driver-api/iio/index.html).
